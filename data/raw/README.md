# Raw data

فایل‌های `Superstore.zip` و `Superstore.sql` را پس از دانلود در این پوشه قرار دهید. این فایل‌ها توسط `.gitignore` از commit شدن مستثنی هستند.

پیش از اجرای SQL، یک دیتابیس MySQL بسازید و در ابتدای نسخه محلی فایل، دستور زیر را اضافه کنید:

```sql
USE YOUR_DB_NAME;
```

فایل SQL شامل دستورات `DROP TABLE IF EXISTS` است؛ فقط روی دیتابیس مخصوص همین پروژه اجرا شود.
