# Project plan

| فاز | خروجی اصلی | مالک پیشنهادی | معیار پایان |
|---|---|---|---|
| Data audit | پروفایل کیفیت شش جدول | Data/BI | خطاها و تصمیم‌های پاک‌سازی مستند شده‌اند |
| Warehouse | مدل ستاره‌ای Power BI | Data/BI | کلیدها و روابط اعتبارسنجی شده‌اند |
| Statistics | آزمون اثر Discount بر Quantity | Statistics | فرض‌ها، effect size، CI و p-value گزارش شده‌اند |
| ML Profit | مدل رگرسیون قابل تعمیم | ML | baseline، CV و test metrics ثبت شده‌اند |
| ML Ship Mode | مدل طبقه‌بندی چندکلاسه | ML | leakage بررسی و macro metrics گزارش شده‌اند |
| Dashboard | گزارش مدیریتی چندصفحه‌ای | BI | همه پرسش‌ها و حداقل دو insight اضافه پوشش داده شده‌اند |
| Presentation | روایت نهایی و پیشنهادها | Team | یافته‌ها قابل دفاع و بازتولید هستند |

## دو تحلیل تکمیلی پیشنهادی داشبورد

1. نرخ مرجوعی و سود خالص به تفکیک محصول، دسته، بازار و روش ارسال
2. تحلیل مشتریان با RFM و شناسایی Segmentهای با ارزش/ریسک ریزش

## ریسک‌های مهم

- نشت هدف در مدل Ship Mode؛ ویژگی‌های ایجادشده پس از انتخاب روش ارسال نباید ورودی مدل باشند.
- شکستن استقلال مشاهدات؛ train/test بهتر است بر اساس Order و ترجیحاً زمان جدا شود.
- فایل PBIX باینری است و merge نمی‌شود؛ مالک ویرایش آن باید هماهنگ باشد.
- معنی آماری بدون effect size و فاصله اطمینان برای تصمیم مدیریتی کافی نیست.
